# Round2 email pictures (SimplyBook emails)
Pictures used by the SimplyBook email frame (Custom Email) and the client email templates. Mail apps recolour text and
backgrounds in dark mode but never pictures, so the Round2 look (black header, pixel font, yellow button) lives in these files.
Made from the real fonts (round2-tv-launcher airplay-webos/receiver/assets/fonts) and menu/img/round2-logo.png.
Don't rename them: emails already sent point at these addresses.
